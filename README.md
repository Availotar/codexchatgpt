# כלי לאיחוד נספחים

המאגר מכיל תסריט שמאפשר למזג נספחים מסוגים שונים (קבצי טקסט, HTML, תמונה ו-PDF) למסמך HTML בודד שמוכן להדפסה או להמרה ל-PDF. התוצר כולל עמוד תוכן עניינים, עמוד שער נפרד לכל נספח ועיצוב מיושר לימין בהתאם להנחיות.

## דרישות

* Python 3.9 ומעלה.
* אין תלות בחבילות חיצוניות – נעשה שימוש בספריות המוכללות בלבד.

## הוראות שימוש

1. צרו קובץ מניפסט בפורמט JSON על בסיס הקובץ [`appendices/manifest.example.json`](appendices/manifest.example.json). רשימת הנספחים צריכה להופיע בסדר הרצוי.
2. לכל נספח ציינו לפחות את שדה `description` ואת הנתיב לקובץ המקור בשדה `file`. ניתן להוסיף את השדה `type` כדי לקבוע את אופי התוכן (`text`, `html`, `image`, `pdf`). כאשר השדה אינו מצוין, הסקריפט ינחש את הסוג לפי סיומת הקובץ.
3. להרצת התהליך:

   ```bash
   python scripts/merge_appendices.py --manifest appendices/manifest.json --output output/merged_appendices.html
   ```

4. הקובץ `merged_appendices.html` יכיל את התוצר הסופי. ניתן לפתוח אותו בדפדפן ולהדפיס ל-PDF כדי לקבל קובץ ממוספר.

## תכונות עיקריות

* הנפקת עמוד שער ממורכז לכל נספח, כולל תיאור קצר.
* הוספת עמוד תוכן עניינים בראש הקובץ.
* יישור לימין ותמיכה מלאה בעברית.
* שילוב הקובץ המקורי בתוך המסמך (באמצעות הטמעה של Base64).
* כל נספח מקבל אות עברית עוקבת (א', ב', ג', ...).

## הערות

* קבצי PDF ותמונות משולבים כ-`embed`/`img` בתוך ה-HTML. בעת המרה ל-PDF ייתכן שהדפדפן יבקש הרשאות תצוגה עבור קבצים מוטמעים.
* אם יש ברשותכם יותר מ-22 נספחים, יש להרחיב ידנית את רשימת האותיות העבריות בקובץ התסריט (`scripts/merge_appendices.py`).
* ניתן לעדכן את כותרת התוכן באמצעות הדגל `--title` בעת הריצה.
